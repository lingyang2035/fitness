# Fitness 部署方案：`https://xx.xxxx.com:9078/fitness/`

---

## 架构

```
浏览器 → https://xx.xxxx.com:9078/fitness/login
                         │
                ┌────────┴────────┐
                │  Nginx 容器      │
                │  02_9078:9078    │
                │                 │
                │  /         → Hiking (9284)
                │  /fitness/ → Fitness (9285:9101)
                └─────────────────┘
                         │
                ┌────────┴────────┐
                │  Fitness 容器     │
                │  9285:9101       │
                │  APP_PREFIX=/fitness
                │  Waitress + Flask │
                └──────────────────┘
```

---

## 一、Nginx 配置（容器 02_9078）

在现有 server 块中，**Hiking 的 `location /` 之前**加入：

```nginx
# ============================================
# Fitness 应用 (子路径 /fitness/)
# ============================================

# 无尾斜杠自动补全
location = /fitness {
    return 301 /fitness/;
}

location /fitness/ {
    # 尾部斜杠剥离 /fitness/ 前缀，代理到 Fitness 容器
    proxy_pass http://<9285容器IP>:9101/;

    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_set_header X-Forwarded-Proto $scheme;

    # 告诉 Flask 原始路径前缀（ProxyFix 中间件会读取）
    proxy_set_header X-Forwarded-Prefix /fitness;

    # Session Cookie 限定在 /fitness/，不泄露到 Hiking
    proxy_cookie_path / /fitness/;

    proxy_http_version 1.1;
    proxy_set_header Upgrade $http_upgrade;
    proxy_set_header Connection "upgrade";
    proxy_connect_timeout 60s;
    proxy_read_timeout 60s;
}
```

生效：
```bash
docker exec 02_9078 nginx -t && docker exec 02_9078 nginx -s reload
```

## 二、Fitness 应用部署（容器 9285）

### 1. 上传代码

```bash
docker cp fitness/ 9285:/opt/fitness/
```

### 2. 安装依赖

```bash
docker exec 9285 pip install flask waitress --break-system-packages
```

### 3. 生成固定密钥（记下来，以后重启复用）

```bash
docker exec 9285 python3 -c "import secrets; print(secrets.token_hex(32))"
```

### 4. 启动应用

```bash
docker exec 9285 bash -c "
cd /opt/fitness && \
APP_PREFIX=/fitness \
SECRET_KEY=你刚才生成的密钥 \
nohup python3 -c \"
from waitress import serve
from app import create_app
serve(create_app(), host='0.0.0.0', port=9101)
\" > /var/log/fitness.log 2>&1 &
"
```

> **`APP_PREFIX=/fitness` 是关键**——它让模板和 JS 中所有路径自动带上 `/fitness` 前缀。

### 5. 验证

```bash
# 容器内验证
docker exec 9285 curl -s -o /dev/null -w "%{http_code}" http://localhost:9101/login

# 通过 nginx 验证
curl -s -o /dev/null -w "%{http_code}" https://xx.xxxx.com:9078/fitness/login
```

## 三、环境变量说明

| 变量 | 必填 | 说明 |
|------|------|------|
| `APP_PREFIX` | 部署时必填 | 设为 `/fitness`，本地开发不设（默认为空） |
| `SECRET_KEY` | 生产必填 | Flask Session 签名密钥，固定值，否则每次重启用户需重新登录 |
| `DATABASE_PATH` | 可选 | SQLite 数据库路径，默认 `data/fitness.db` |

```bash
docker exec 9285 pkill -f waitress

SECRET_KEY=你的密钥 \

```

## 六、本地开发

不需要 `APP_PREFIX`，直接运行：

```bash
cd fitness
python3 run.py
# 访问 http://localhost:5000
```

所有路径自动适配——设了 `APP_PREFIX` 就带前缀，不设就是原始路径。
